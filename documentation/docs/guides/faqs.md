# Frequently Asked Questions
   - How do I resend a BoxSign Request?
   - I need to resend a BoxSign Request to a new email address; the first one was lost.
      - Policy
         - You may only resend a BoxSign Request to the existing email address. Purchasing has the permission to do so.  
         - In the event the vendor did receive the email, but clicking on the link reveals that it has expired, they have a small link on the bottom of that page which will allow them to resend the BoxSign Request themselves.
         - In the event you need to change to whom the email is being sent, you must cancel the original BoxSign Request, delete the Signed files, and Signing Log, and create a new BoxSign Request to the new email address.  You should update the email address in the Vendor Metadata Template before this is done.
            
   - I receive a 500 Error view opening a contract
      - Submit a Helpdesk Ticket.  Make sure to specify the contract number and associated supporting documentation.

   - I receive a blank screen when I first open a contract.
      - Document generation does take a minute to create a viewable file. When a contract is first created, it will almost always show a blank screen. Simply refresh the page and the document should appear. 

   - I refreshed the page and the contract still doesn't appear; or there is an error on the page.
      - This is common with different browsers. If you're using Microsoft Edge, switch to Chrome. If chrome is giving you issues as well, Firefox seems to be the only browser without problems. When all else fails, submit a help desk ticket. Make sure to specify the contract number and associated supporting documentation.
