# Best Practices

### Use Original Electronic Files when possible

Whenever possible, upload the original electronic file to the system, instead of scans.  
This system utilize Full Text Search Indexing.  When a file is printed and scanned it now longer 
contains characters, but rather an image of the characters, which cannot be interpretted by the system.

In general, here is a list of preferred formats:

- Word Documents (.doc, .docx)
- Original PDF Files (when saving Word Documents in PDF format, or creating PDF files directly in an Acrobat Professional Application)
- Scanned Documents (These formats are accepted but as a last resort.)

### Use Box Sign for all Signatures

We are adopting electronic signatures in full with the ECM.  Handwritten (wet) signatures are no longer required and should not be used 
due to the fact that it requires a scanned document, further restricting our search capabilites.

When a contract reaches the Mayor's office, a Box Sign Request is submitted to the vendor.  Allowing them to
sign the document electronically without the need for a Box Account.  They can accomplish this on all devices, including workstations, tables and cell phones.

We have the capabilites of signing supporting documentation as well.  Here are some examples of documents that can be electronically signed:

- Department Head Certification Page
- Vendor supplied documentation (Statement of Work, Quote, Terms)
- Certificate of Insurance

### Use the Uniform Contract Generator when possible

Forms are available via the Home Ribbon.  New forms are created and posted all the time.  Only in the event a form is not available should a contract 
be created with the Import Feature.  Even then, as with vendor supplied contracts, the original electronic files should be used whenever possible.
